## 基本概念

### RNNとは

RNN（Recurrent Neural Network、再帰型ニューラルネットワーク）は、**時系列データ**を処理するために設計されたニューラルネットワークの一種です。

**通常のニューラルネットワークとの違い：**

| 特性 | 通常のNN | RNN |
|------|---------|-----|
| 入力の形式 | 固定長ベクトル | 可変長シーケンス |
| メモリ | なし | あり（隠れ状態） |
| 情報の流れ | 単方向 | ループあり |
| 用途 | 分類、回帰 | テキスト、時系列予測 |

### RNNの特徴

1. **可変長入力への対応**
   - 短い文も長い文も同じアーキテクチャで処理可能

2. **文脈の保持**
   - 過去の情報を隠れ状態として保持し、次のステップに引き継ぐ

3. **重みの共有**
   - 全ステップで同じ重み行列を使用するため、パラメータ数が効率的

## RNNの数学的定義

### 基本的な計算式

RNNの各時刻 $t$ における計算は以下の式で表されます：

$$h_t = \tanh(W_h h_{t-1} + W_x x_t + b)$$

$$y_t = W_y h_t + b_y$$

**記号の説明：**

| 記号 | 意味 | 形状 |
|------|------|------|
| $x_t$ | 時刻 $t$ の入力ベクトル | $(d_{in}, 1)$ |
| $h_t$ | 時刻 $t$ の隠れ状態 | $(d_h, 1)$ |
| $h_{t-1}$ | 時刻 $t-1$ の隠れ状態 | $(d_h, 1)$ |
| $y_t$ | 時刻 $t$ の出力ベクトル | $(d_{out}, 1)$ |
| $W_x$ | 入力→隠れ状態の重み行列 | $(d_h, d_{in})$ |
| $W_h$ | 隠れ状態→隠れ状態の重み行列（再帰重み） | $(d_h, d_h)$ |
| $W_y$ | 隠れ状態→出力の重み行列 | $(d_{out}, d_h)$ |
| $b, b_y$ | バイアス | $(d_h, 1)$, $(d_{out}, 1)$ |
| $\tanh$ | 双曲正接活性化関数 | - |

## 隠れ状態とメモリ

### 隠れ状態とは

隠れ状態 $h_t$ は、RNNの「メモリ」です。

$$h_t = f(h_{t-1}, x_t)$$

- $h_{t-1}$：過去の情報
- $x_t$：新しい入力
- $h_t$：過去と現在を統合した情報

### メモリの更新メカニズム

隠れ状態は次のように段階的に更新されます：

**ステップ 1：入力と前の状態を重み付け**

$$\tilde{h}_t = W_x x_t + W_h h_{t-1} + b$$

**ステップ 2：活性化関数を適用**

$$h_t = \tanh(\tilde{h}_t)$$

**ステップ 3：出力を計算**

$$y_t = W_y h_t + b_y$$

### 数値例

簡単な例で説明します。 $d_h = 3$  (隠れサイズ=3) と仮定：

**時刻 1：**
- 入力: $x_1 = [1, 0]^T$ (最初の単語"a")
- 初期隠れ状態: $h_0 = [0, 0, 0]^T$
- 新隐れ状態: $h_1 = [0.2, -0.1, 0.3]^T$

**時刻 2：**
- 入力: $x_2 = [0, 1]^T$ (次の単語"b")
- 前の隠れ状態: $h_1 = [0.2, -0.1, 0.3]^T$ ← **前ステップの情報を保持**
- 新隐れ状態: $h_2 = [0.1, 0.2, 0.15]^T$

**時刻 3：**
- 入力: $x_3 = [1, 1]^T$ (次の単語"c")
- 前の隠れ状態: $h_2 = [0.1, 0.2, 0.15]^T$
- 新隐れ状態: $h_3 = [0.3, 0.05, 0.25]^T$

👉 隠れ状態 $h_3$ には、"a", "b", "c" すべての情報が圧縮されて保持されています。

## 時系列処理

### シーケンスの処理フロー



入力シーケンス: [x_1, x_2, x_3, ..., x_T]
時刻 1: h_0 → RNN → h_1 → y_1
        ↓
時刻 2: h_1 → RNN → h_2 → y_2
        ↓
時刻 3: h_2 → RNN → h_3 → y_3
        ↓
時刻 T: h_{T-1} → RNN → h_T → y_T
最終隠れ状態 h_T: 全入力の情報を保持


### 例：テキスト分類

入力：「このケーキはおいしい」



時刻 1: [このケーキはおいしい] → h_1
        ↓
時刻 2: [ケーキはおいしい] (前情報付き) → h_2
        ↓
時刻 3: [はおいしい] (前情報付き) → h_3
        ↓
時刻 4: [おいしい] (前情報付き) → h_4
        ↓
分類層: h_4 → [肯定確率: 0.95]

## 訓練：BPTT

### BPTTとは

BPTT（Backpropagation Through Time）は、RNNを訓練するためのアルゴリズムです。通常のバックプロパゲーションを**時間軸に展開**して適用します。

### 損失関数

シーケンス全体の損失：

$$L = \sum_{t=1}^{T} L_t = \sum_{t=1}^{T} -\log P(y_t | x_1, ..., x_t)$$

- $L_t$：時刻 $t$ での損失
- $T$：シーケンスの長さ

### 勾配計算の流れ

各時刻 $t$ での勾配は、その時刻での勾配と、すべての未来の時刻からの勾配の合計です：

$$\frac{\partial L}{\partial h_t} = \frac{\partial L_t}{\partial h_t} + \frac{\partial L_{t+1}}{\partial h_t} + ... + \frac{\partial L_T}{\partial h_t}$$

これは連鎖律で：

$$\frac{\partial L}{\partial h_t} = \frac{\partial L_t}{\partial h_t} + \frac{\partial h_{t+1}}{\partial h_t} \cdot \frac{\partial L}{\partial h_{t+1}}$$

### 重み行列 $W_h$ の勾配

最重要な点として、 $W_h$ の勾配は全ステップの勾配から計算されます：

$$\frac{\partial L}{\partial W_h} = \sum_{t=1}^{T} \frac{\partial L}{\partial h_t} \cdot \frac{\partial h_t}{\partial W_h}$$

---

## 勾配消失問題

### 問題の本質

BPTTで時刻を遡るとき、勾配は連鎖律により乗算されます：

$$\frac{\partial h_1}{\partial W_h} = \frac{\partial h_T}{\partial h_{T-1}} \cdot \frac{\partial h_{T-1}}{\partial h_{T-2}} \cdot ... \cdot \frac{\partial h_2}{\partial h_1}$$

各項は：

$$\frac{\partial h_t}{\partial h_{t-1}} = \text{diag}(\tanh'(\tilde{h}_t)) \cdot W_h$$

**問題：**

$$\tanh'(x) = 1 - \tanh^2(x) \leq 1$$

- $\tanh$ の導関数の最大値は0.25（ $x=0$ 付近）
- 行列 $W_h$ も通常は正規化されているため、その最大特異値は1前後

**結果：**

$$\left| \frac{\partial h_t}{\partial h_{t-1}} \right| \leq 0.25 \times 1 = 0.25$$

時刻を遡るたびに勾配が0.25倍になります：

$$\left| \frac{\partial L}{\partial W_h^{(t=1)}} \right| = \lambda^{T-1} \times \left| \frac{\partial L_T}{\partial h_T} \right|$$

ここで $\lambda \approx 0.25$。

**具体例：**

$$\text{勾配の大きさ} = 0.25^{10} \approx 9.5 \times 10^{-7}$$

10ステップ前の勾配は、ほぼゼロになってしまいます！

### 影響

- **遠い過去の学習が困難**：10単語以上前の文脈を学習できない
- **初期情報の喪失**：長い文の最初の方の重要な情報が失われやすい

### 可視化



時刻 1    時刻 2    時刻 3    時刻 4    時刻 5
  |        |        |        |        |
勾配: 0.001   0.004   0.016   0.063   0.25
  ↑ ↑ ↑ ↑ ↑
勾配が時刻を遡るにつれて指数関数的に縮小

## 具体例

### 例1：単語の次の単語予測

**入力文：** 「私は毎日___へ行く」



時刻 1: 入力 = "私" (embedding)
        h_1 = tanh(W_x × embedding("私") + W_h × 0 + b)
        y_1 = softmax(W_y × h_1) → 次の単語確率分布
時刻 2: 入力 = "は"
        h_2 = tanh(W_x × embedding("は") + W_h × h_1 + b)
        ↑注意：h_1 に「私」の情報が含まれている
        y_2 = softmax(W_y × h_2)
時刻 3: 入力 = "毎日"
        h_3 = tanh(W_x × embedding("毎日") + W_h × h_2 + b)
        ↑注意：h_2 に「私は」の情報が含まれている
        y_3 = softmax(W_y × h_3)
時刻 4: 入力 = なし（予測フェーズ）
        次の単語は y_3 から予測
        h_3 の情報から「行く」の次に来やすい場所を予測
        → 「学校」「仕事」「家」などが高確率


### 例2：感情分類

**タスク：** 映画レビュー全体の感情を分類

**入力：** 「このケーキはおいしかったけど、値段が高すぎる」



時刻 1: "このケーキは" → h_1
時刻 2: "おいしかったけど" (+ h_1) → h_2
時刻 3: "値段が" (+ h_2) → h_3
時刻 4: "高すぎる" (+ h_3) → h_4
最終隠れ状態 h_4 には、文章全体の情報が圧縮
分類層：h_4 → [肯定: 0.45, 否定: 0.55]
         （肯定と否定の要素が混在しているため、中立的な判定）


### 例3：言語モデル（テキスト生成）

**タスク：** 次の文字を予測

**入力：** "hell"



時刻 1: h = tanh(W_x × encoding("h") + 0)
        予測: "h" の次に来やすい文字（たぶん"e"）
時刻 2: h = tanh(W_x × encoding("e") + W_h × h_prev)
        予測: "he" の次に来やすい文字（たぶん"l"）
時刻 3: h = tanh(W_x × encoding("l") + W_h × h_prev)
        予測: "hel" の次に来やすい文字（たぶん"l"）
時刻 4: h = tanh(W_x × encoding("l") + W_h × h_prev)
        予測: "hell" の次に来やすい文字（たぶん"o"）
結果：h → e → l → l → o → 「hello」を生成！

## まとめ

### RNNの強み
✅ 可変長シーケンスを処理可能
✅ 文脈情報を隠れ状態として保持
✅ パラメータ効率が良い

### RNNの弱み
❌ 長期依存関係の学習が困難（勾配消失）
❌ 順序処理のため並列化が難しい
❌ 訓練が遅い

### 次のステップ
これらの弱点を克服するために、**LSTM** と **GRU** が開発されました。
